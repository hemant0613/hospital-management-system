# Hospital Management System

Enterprise-level Hospital Management System using DevOps culture.

## Tech Stack

- Python (FastAPI)
- PostgreSQL
- Docker
- Kubernetes
- Jenkins
- Ansible
- Prometheus
- Grafana

## Services

- Authentication Service
- Patient Service
- Doctor Service
- Appointment Service
- Billing Service
- Notification Service

## DevOps Goals

- CI/CD using Jenkins
- Containerization using Docker
- Kubernetes orchestration
- Infrastructure automation
- Monitoring and observability
